# 潮汐集市 · 奶娃的海上商站（网页版）

轻量浏览器游戏，使用 Canvas 等距视角绘制浮岛，以原图风格的透明 PNG 展示奶娃、仁博、晁瑞和食物供应商。点击链接直接游戏，无需安装引擎。

玩法：打捞 → 扩建 → 制作 → 向 NPC 交付 → 获得金币与声望。食物供应商出售临时样例猪脚饭，8 金币/份，放入背包后可用于远航补给箱。没有引入居民经营、饥饿惩罚或收费功能。

## 出海与体力

- 只有出海时才能打捞。每次出海消耗 1 点体力，当前上限 6 点，单次航行 60 秒，可提前返航，不退还已消耗体力。
- 主要通过「随机打捞」获得物资，间隔 6 秒；物资及数量按 `settings.salvage_loot` 随机。
- 海面偶遇物资只在出海时出现，间隔约 18 秒；第一次出海只生成一件初始漂浮物。
- 每小时自然恢复 1 点体力，计算浏览器关闭期间的时间；满体力不积攒额外恢复次数。
- 吃一份猪脚饭恢复 2 点体力，不超过上限。满体力时不可食用，不会浪费食品。
- 航行剩余时间、体力、恢复计时和随机打捞冷却均保存；刷新页面不会免费重置体力，也不会重开航行时长。
- 出海中只能收集和吃背包中的食物；建造、安排新制作、购买食物和交付订单需要返航。已开始的制作继续执行。

当前体力与时间由浏览器本地管理，无服务器防作弊或账号同步。

## 樾与便

- 樾默认出战，在伙伴面板切换同行 / 休息；海上不可切换。同行成功随机打捞 +1 经验，首级 5 次升级，此后每级需求增加 2 次，最高 10 级。直接拾取不加经验。
- 每级平均数量加成 +20%，用概率取整保留小数收益；精良概率为 10% + 等级 ×2%，稀有概率为 2% + 等级 ×1%，其余为普通原料。数量受仓库容量限制。
- 精良和稀有货物是实际库存，远行商会在玩家持有时随机提供收购订单，分别 24 / 60 金币每件。
- 便以深蓝上衣、长裤、照片风格头像和锤子的简化地图人物出现。平台扩建由他施工 4 秒，扣费一次，完成后可使用；当前项目未完成时不可再开扩建。存档保留施工进度。出海期间岛上的施工继续，暂停 / 后台不推进施工。
- 两个人物的资产及最终 ImageGen 提示词见 `COMPANION_WORKER_NOTES.md`。

- 主角：奶娃，点击空平台移动。
- 引导员：仁博（建造与打捞）、晁瑞（制作与交易）。
- 食物供应商：用户提供的灰衣动漫人物，立绘去除背景与字幕；名称暂用「食物供应商」。
- 桌面：鼠标点击、滚轮缩放、WASD 平移、Q/E 旋转、R 旋转建筑、F 回到浮岛。
- 手机：触摸打捞/建造，拖动空白海面平移；底部按钮打开工坊、订单和食堂。

## 本地运行与测试

`node serve.mjs` 启动于 `http://127.0.0.1:8787`。`node --test tests/*.test.mjs` 验证交易与存档。

`dist/` 即发布目录，无框架、无远程 JS 依赖。所有角色图片均存放在 `dist/assets/`。数据源与桌面原型共用：

- `C:/Users/wzl/Desktop/CODE2/ocean-trader/data/catalog.json`
- `C:/Users/wzl/Desktop/CODE2/ocean-trader/data/characters.json`

修改后同步到 `dist/data/`；网页角色图片路径使用 `./assets/`，桌面版使用 `res://characters/`。

## 存档与边界

进度保存在当前浏览器的 localStorage，每二十秒自动保存，离开页面保存。不同浏览器、设备和网站域名的存档独立；没有账号云存档。新局窗口可下载 JSON 存档备份。无离线生产奖励，窗口处于后台时暂停计时。

供应商购买会保留建造首个加工台所需的启动金币，避免开局花完金币后无法进入制作循环。

角色图片采用内置 imagegen 透明背景处理，提示词在 `ASSET_NOTES.md`。原始私人参考照片不包含在发布目录或上传的源码中；网页只包含用户要求用于游戏的角色立绘。
